Setup Instructions

1. Clone or download this repository and open the project folder in a code editor (such as VS Code).
   
3. Ensure books.json, books.html, and jquery-dom.html are placed in the expected directory (and books.json is accessible alongside books.html).
   
5. Run the files using a local development server (such as VS Code Live Server):
   - Question 1 (books.json): Open books.json in your code editor or inspect/parse it via a local server / browser console to verify valid JSON syntax.
   - Question 2 (books.html): Open books.html through a local server (for example, http://127.0.0.1:5500/books.html) do not open it directly using file:// so fetch() can load books.json properly.
   - Question 3 (jquery-dom.html): Open jquery-dom.html in a modern web browser (with internet access for the jQuery 4.0.0 CDN) and test the text update, styling, and button click alert.
